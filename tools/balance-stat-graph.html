WildStat / balance tool

Map stat multipliers

Authored values plotted directly from the current game rules. Each point is current map ÷ previous map; Tutorial Forest is the baseline. Combat values are spawn-weighted means. Regular reward rows keep every enemy's authored payout separate, and boss rewards are the full payout on every clear.

Combat pressure

Regular damage is the strength proxy. Boss heavy hit is the largest authored boss ability.

Individual rewards

Every regular enemy payout is its own series—never an average. The enemy name appears beneath each value; boss rewards are per clear and repeat at 100%.

Numbers behind the lines

Each cell shows the authored value first. Regular-reward cells name the source enemy and show its map-step multiplier underneath. A dash means that source does not exist.

No simulation output is used here. Combat uses actual spawn-site composition; reward rows read each current enemy definition directly without pooling or averaging rewards.
