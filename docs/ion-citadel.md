# Ion Citadel

Ion Citadel follows Verdant Catacombs. Defeat Gravebloom to unlock its forward portal. Existing Gravebloom claim bits or positive contributions to the latest defeated encounter are restored by migration 30. The return portal leads to Verdant Catacombs.

Five camps contain 30 spawn sites, using the original green shield sentry from the reserved neon set:

| Camp | Enemy roles |
| --- | --- |
| Shield Gate | Ion Patrol |
| Capacitor Court | Capacitor Gunner, Citadel Marshal |
| Armored Rampart | Bastion Defender |
| Flux Assembly | Flux Enforcer |
| Reactor Annex | Reactor Warden |

Every role uses the same archived guardian animation, with the established camp sizes, ranged behavior, elite sizes, and stat rewards. The previous sword sentry remains in Neon Bastion. Four other neon designs remain available for future regions.

Aegis Prime is an original vector shield commander. Its shield sweep telegraphs a frontal sector; the rear remains open. Three staggered ion bursts target a line through the player's recorded position, rotating the line on alternate volleys. Movement out of the target circles avoids the burst. The boss has its own multiplayer encounter, damage budget, repeatable stat rewards, and claim bit.

The terrain uses connected reactor courtyards, armored plates, mint conduits, and capacitor towers. Boss and arrival areas remain clear. The map is integrated with the guide, auto-farm, home return travel, asset loading, map editor, balance tools, and root/map server modules.

This expansion uses protocol 100 and migration 30. Its client and both server modules must be released together. Visual review belongs to the user.
