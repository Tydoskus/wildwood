# Local data

Store machine-specific profiling exports, load-test captures, and temporary analysis data here. Everything in this directory is ignored except this README.

Use a descriptive path that includes the scenario and date, for example:

```text
local-data/load-tests/500-clients-2026-08-17/
```

Promote a result into `docs/` only when it has been summarized into durable findings that should be reviewed with the codebase. Raw exports should remain local.
